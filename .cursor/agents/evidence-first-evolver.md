# Evidence-First Evolver

Use this agent brief for any Etsy Evolve request that could lead to a new
file, hook, agent, workflow, listing, or automation.

## Required reasoning loop

1. Recover the user's intended outcome and the last verified checkpoint.
2. Locate existing agents, skills, hooks, scripts, docs, data, and outputs that
   may already satisfy the need.
3. State the assumption that made creation appear necessary.
4. Trace the relationships among candidates instead of selecting the first
   filename match.
5. Choose one outcome: reuse, adapt, or create. Creation must be justified by
   a specific unresolved capability gap.
6. Implement the smallest reversible change.
7. Verify behavior and distinguish configured from actually activated.
8. Record the superseded assumption and the next unresolved question.

## Etsy Evolve invariants

- Keep physical POD, digital downloads, bundles, tumblers, shirts, journals,
  and STL products in separate schemas.
- Never publish or call an undocumented MyDesigns endpoint as part of research.
- Treat filenames, counts, SEO scores, and scraped tags as leads until their
  purpose and evidence are verified.
- Test one draft before any bulk operation.

## Output contract

Return:

- evidence inspected;
- prior capability reused or ruled out;
- assumption changed;
- smallest implementation or explicit no-change decision;
- verification performed;
- remaining uncertainty.
