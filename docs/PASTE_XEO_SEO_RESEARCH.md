## Reconciled vocabulary

| Layer | Working meaning in the saved material | Safe Etsy application |
|---|---|---|
| SEO | Conventional search optimization | Product-first titles, relevant tags, readable descriptions, image metadata |
| AEO | Answer Engine Optimization | Answer-first FAQs and concise buyer guidance on owned pages |
| GEO | Generative Engine Optimization | Clear, source-backed pages that explain products and methods; never promise citation placement |
| DEO | Device/Display Engine Optimization | Mobile-readable thumbnails, accessible alt text, responsive pages, and platform-specific crops |
| VEO | Value Engine Optimization | Proof of work, included-file clarity, examples, licenses, and buyer outcomes |
| EEO | Experience Engine Optimization | Fast pages, understandable navigation, honest previews, and low-friction downloads |
| LEO | Legal/Ethical Optimization | Rights checks, trademark avoidance, privacy, disclosure, and platform compliance |
| BEO | Behavioral Engine Optimization | Useful repeatable buyer journeys; avoid manipulative dark patterns |
| NEO | Network Engine Optimization | Ethical participation and earned mentions in communities; no automated unsolicited posting |
| KEO | Kinetic Engine Optimization | Motion/video/AR presentation when it genuinely helps the product; for Etsy, use the verified tumbler video/profile rules |
| OEO | Oracle/verification layer | Evidence ledger, source links, confidence labels, and human review before publishing |
| TKEO | Kinetic/timeliness layer in one saved strategy | Freshness through legitimate updates and changelogs, not artificial publishing volume |

These labels are a planning vocabulary, not a claim that search engines recognize each acronym as an official ranking system. In this repository, OEO/LEO are quality gates, while SEO/AEO/GEO/DEO describe content and presentation work that can be tested.

## What carries into Etsy-evolve

1. Keep the two-domain architecture separate from Etsy listing schemas. AvatarArts can own creative asset automation, AI video, visual/audio workflows, and product examples; QuantumForgeLabs can own automation architecture, validators, metadata systems, and technical documentation.
2. Translate the XEO layers into a single Etsy listing QA loop: product truth → useful answer blocks → readable images → value proof → rights check → manual draft review.
3. Use the saved keyword clusters as hypotheses only. The earlier local Etsy audit remains authoritative for tumbler terms such as `20oz tumbler wrap`, `tumbler wrap PNG`, `straight and tapered`, `sublimation design`, and `digital download`.
4. Build content around verifiable demonstrations: before/after image processing, real mockup slot validation, actual file manifests, and documented workflow runs.

## Explicit exclusions

The Paste material proposes or mentions tactics that do not belong in this project:

- auto-injecting promotional replies into Discord, Slack, Reddit, WhatsApp, or Etsy communities;
- PBNs, expired-domain manipulation, traffic arbitrage, or “parasite SEO” campaigns;
- claiming that a page will be cited by ChatGPT, Perplexity, or Google AI simply because it uses FAQ/HowTo schema;
- treating copied growth percentages, Gartner references, or “top 1–5%” labels as verified without the underlying source;
- publishing large volumes of low-value AI pages or automated trend reports without human review.

The safe substitute is an evidence-backed content and listing system with explicit source IDs, dates, limitations, rights checks, and draft-level approval.
