# Etsy posting packs

Posting drafts generated from the local examples audit, existing mockup guides,
Notion XEO research, and Paste terminology review. These are templates for
manual review. They are not live listings and do not claim bestseller status.

## Global posting rules

- Put the product and format first; put the motif/audience second.
- Use only tags supported by the actual file or physical product.
- Say `digital download` and `no physical item` when applicable.
- Keep physical POD, digital artwork, printable files, and STL delivery
  separate.
- Do not copy protected franchise names, characters, logos, or celebrity terms.
- Treat saved growth figures, ranking forecasts, and competitor prices as
  unverified until rechecked.
- Use a clean single-product hero; use collages only when the bundle itself is
  the product.

## Posting QA

- [ ] Product family matches the title, photos, delivery, and category.
- [ ] Every keyword describes something visible or delivered.
- [ ] No protected character, franchise, or trademark shortcut.
- [ ] Description states physical versus digital clearly.
- [ ] File formats, sizes, and license are verified.
- [ ] Hero image is readable at thumbnail size.
- [ ] Source/provenance and rights status are logged.
- [ ] Draft is reviewed before bulk creation.
