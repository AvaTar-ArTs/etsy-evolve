# Creative expansion plan

The agent inventory suggests three useful modes for Etsy-evolve:

- `trend-researcher`: identify a signal, distinguish a short spike from a
  durable opportunity, and attach a next test;
- `seo-keyword-analyst`: separate search intent, product fit, difficulty, and
  current validation from saved keyword folklore;
- `ui-designer`: make the evidence usable, responsive, and implementation-ready.

The static surface now expresses those modes as:

| Mode | Page | Job |
|---|---|---|
| Trend synthesis | `site/catalog.html` | choose the proof profile for a product family |
| Keyword analysis | `site/keyword-lab.html` | filter product-first keyword seeds |
| Posting | `site/posting-packs.html` | turn verified fields into copy structure |
| Provenance | `site/source-review.html` | inspect source quality and uncertainty |

## Next expansion loop

1. Add one real candidate asset per family.
2. Record its source, rights status, dimensions, and delivery files.
3. Select one keyword seed from the lab.
4. Generate a posting draft and mockup order.
5. Review one draft before adding more candidates.

The client-side filter is intentionally small and dependency-free. It is a
prototype of the future manifest-driven catalog, not a replacement for current
Etsy or MyDesigns validation.
